# Демо кроссплатформенной State Driven навигации

Это демо приложение кроссплатформенной State Driven навигации при которой на разных платформах может быть разная навигация и разный набор экранов при одинаковых адресах в строке браузера. Достигается это благодаря тому, что адреса привязываются не к конкретному экрану, а к тому, что сейчас делает пользователь. При этом переключение между платформами и навигацией происходит бесшовно.
